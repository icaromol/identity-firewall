Identity Firewall — manual test pages

Each link below is a separate origin (its own port), so the extension treats each one as a distinct site with its own Service Identity -- exactly like real different websites would.

  • Signup form -- all 6 PersonalData fields, required + optional mix, autocomplete="new-password".
  • Login form -- identifier + autocomplete="current-password".
  • Personal-data disclosure -- no password field, tests the approval matrix and "Deny optional fields."
  • "Bank" site -- nationalId + the Safe Mode (government/financial) toggle.
  • Dynamic SPA form -- known limitation: never detected.
  • Multi-step wizard -- known limitation: hidden step can be silently filled.
